## Идеи

- Локальный плагин-конвертер скриптов субагентов в сохранённые workflow (`.pi/workflows/*.js`) — чтобы типовые многоагентные сценарии запускались одной командой.
- Сравнить `pi-live-throughput` с `pi-tokometer` и `@pi-plugins/speed` по точности TTFT на reasoning-моделях (`thinking max`) — сейчас замеры делались на синтетике.
- Проверить влияние `compaction.reserveTokens 16384` / `keepRecentTokens 20000` на длинных сессиях с 1M-контекстом: не режет ли слишком агрессивно.
- Собрать таблицу «какой thinking-уровень → сколько реально токенов thinking» на `deepseek-flash` (уровень `max` включён по умолчанию).
